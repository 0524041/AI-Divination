# 06 — 追問、中止、重試與訪客限額

**What to build:** 對話開放：同一占卜紀錄內 POST 追問、經同一 SSE 通道串流回應；生成中可中止（上游請求一併取消）；可重試重新生成最後一則助手訊息。訪客每日上限 10 則 AI 回應（含首次解盤），集中單一限制點，額度餘量隨 API 可查。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 追問端點：user 訊息持久化 → 上下文＝system＋盤面摘要＋滑窗對話史 → 串流回應
- [ ] 中止：SSE 中斷即取消上游生成；部分回應依設計處理（捨棄並標記取消）
- [ ] 重試：最後一則 assistant 訊息重新生成替換
- [ ] 訪客限額 enforcement point：第 11 則回應被拒、錯誤語意明確、餘量可查
- [ ] 登入使用者不限額

## 測試項目（Seam①）
1. 多輪上下文：第二輪請求的 messages 含盤面摘要＋先前對話（假伺服器驗證收到的內容）
2. 滑窗：對話史超過上限時僅保留最近 N 則＋盤面摘要恆在
3. 中止時序：delta 中途中斷→上游收到 cancel→該回應標記取消→後續追問仍正常
4. 重試：替換語意正確（舊內容不留雙份）、tokens/用量重記
5. 限額邊界：第 10 則成功、第 11 則拒絕、錯誤碼與訊息正確、跨日重置
6. 限額只計 AI 回應：使用者輸入被拒時不消耗額度
7. 登入用戶不受限；訪客+登入狀態切換的計數歸屬正確
